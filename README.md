# Pacman Game - JavaFX

This is a **Pacman game** built using **JavaFX**.

## How to Run
- Run the `App.java` class to start the project.
- A game panel will open where you can control Pacman using **arrow keys**.

## Gameplay Instructions
- Use arrow keys (**Up, Down, Left, Right**) to move Pacman around.
- If Pacman hits a wall, he will either stop or you can change his direction.
- Collision with a ghost will cause Pacman to **lose a life**.
- You start with **3 lives**.
- Food is placed across the panel:
  - Eating a food item gives **+10 score**.
  - The score is updated live, and a **high score** is tracked.
- Once all the food is eaten, the game **reloads** automatically.
- If you lose all 3 lives, the game **restarts**.

## Features
- Smooth player control using keyboard arrows.
- Wall collision detection.
- Ghost collision and life loss system.
- Score and high score tracking.
- Automatic game reload after food completion or all lives lost.
- More features will be added in future updates!
